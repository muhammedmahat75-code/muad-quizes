📦 Understanding the Box Model

Margin · Padding · Border · Width / Height

Open DevTools (Inspect) → Elements → Computed to see each box's dimensions

🔲 Box 1: content-box (default)

content

width: 200px
height: 120px

margin: 30px (outside)  |  padding: 20px (inside)  |  border: 6px solid

📐 Total width = width + padding + border = 200 + 40 + 12 = 252px

The content-box model adds padding & border outside the set width/height.

🔲 Box 2: border-box (modern)

content

width: 200px
height: 120px

border-box

margin: 30px  |  padding: 20px  |  border: 6px solid

📐 Total width = width (includes padding + border) = 200px

With border-box, padding and border are inside the defined width/height. Much easier to control!

🔲 Box 3: large margin & padding

content

width: 180px
height: 100px

+ 48px padding

margin: 40px (huge)  |  padding: 48px (thick)  |  border: 10px dotted

📐 Total width = width + padding + border = 180 + 96 + 20 = 296px

Big margins push other elements away; big padding expands the inner space.
Notice how the background fills the padding area.
