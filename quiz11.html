Four positioning types + sticky header

Each colored box shows a different position value.
Scroll the page to see fixed (bottom-right) and sticky (header) in action.

📐 Use DevTools → Elements → Computed to inspect each box's position.

🔹 position: static

static

Default flow.
Top/left/right/bottom have no effect.

📄 normal flow

static is the default. The box stays in the normal document flow. Offset properties (top, left, etc.) are ignored.

🔸 position: relative

relative

Offset from its normal position.
(top: 20px; left: 30px)

↕️ shifted

relative positions the box relative to where it would normally be. Other content is not affected (gap remains).

🔶 position: absolute

absolute

Positioned relative to nearest positioned ancestor.
(top: 10px; right: 10px)

🎯 anchored

⬅️ This container is position: relative.
The absolute box is placed inside it using top: 10px; right: 10px;

absolute removes the element from the normal flow and positions it relative to the nearest positioned ancestor (here, the .pos-wrapper).

🔷 position: fixed

fixed

Positioned relative to the viewport.
(bottom: 30px; right: 30px)

📌 always visible

fixed is positioned relative to the viewport. It stays in the same place even when scrolling. (This box is in the bottom-right corner.)
